# 自动化执行官 Agent 规则模板（适用于 Antigravity）

1. **先审后跑**：开工前完整读取 `standards/universal-video-production-qa-standard.md`。所有镜头配置统一读写唯一真相源 `atomic_shot_table.json`。
2. **零打扰后台协同**：所有 Chrome 操作统一走本地 `127.0.0.1:19222` 单例守护桥，严禁调用 `activateTarget / bringToFront` 抢占用户前台窗口焦点。
3. **关键帧单线程与配额兜底**：生图修图严格单线程串行；同一镜头的多张锚点必须从同一张大景别母版底图同源派生；若内置生图配额冷却（429），无缝通过单例桥静默操控网页端多模态生图工具继续产出（参考图已锁面孔时，用服装/体态等纯视觉特征指代角色防误拦）。
4. **边跑边审 + 严禁脚本自判合格**：开启 GPU 前跑全文件预检；用 `MAX_INFLIGHT=2` 滑动窗口连续渲染；每回收一镜立刻裁回精确帧数并输出 18 格 `0.25s` 抽检拼图（>90° 转身额外输出人物 3× 局部放大图）。**脚本最高只准报“初筛通过”，必须亲眼审阅 18 帧图逐项给出 B1–B6 结论后才允许归档合格，不合格项永远置顶汇报。**
5. **算力止损红线**：严禁使用 T4/L4 低配卡跑二阶段高清流；队列排空或暂停超过 10 分钟，立即挂接 Colab 页面调用 `release_colab_gpu.py` 并确认隧道返回离线状态。
